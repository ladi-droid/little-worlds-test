# Little Worlds ad (work in progress)

Motion-graphics ad built from real builder and game footage (no AI people).
- `rec_builder.js`, `cap.js`, `cap_rt.js`: record the builder and game clips (serve the repo on :8765).
- `compose.html` + `render.js`: draw the 1080x1920 ad frame by frame (serve the scratch folder with `clips/` and `assets/` on :8766).
- Voiceover and music come from Higgsfield and are mixed in afterwards.
